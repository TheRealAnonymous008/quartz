* A **projective plane** is a [[Incidence Structure|partial linear space]] where
	* Any two lines meet at a unique point
	* Any two points lie in a unique line.
	* There are three pairwise non-collinear points (a triangle).

* A projective plane is self-[[Graph Duality|dual]]. 

* Let $\mathcal{I}$ be a partial linear space that contains a triangle. Then $\mathcal{I}$ is a projective plane if and only if its incidence graph $X(\mathcal I)$ has diameter $3$ and girth $6$.

* The incidence structure $\text{PG}(2,q)$ is called the **projective field plane** and is described as follows:  Points and lines correspond to $1$-D and $2$-D dimensional [[Vector Subspace|subspaces]] of [[Vector Space|vector space]] $V\subseteq \mathbb{F}^3$ where $\text{ord}(\mathbb{F})=q$. 
	* $p$ is incident with line $L$ if the subspace of $p$ is contained in the subspace of $L$. 
	* Each line contains $q^2-1$ nonzero vectors. 
	* Each point contains $q-1$ nonzero vectors.
	* Each line contains $q+1$ distinct points. 
	* The entire projective plane contains $q^2+q+1$ points.
	* The projective plane contains  $q^2+q+1$ linens with $q+1$ lines passing through each point.
	* It is easy to show that *$PG(2,q)$ is a projective plane*
	* The corresponding incidence graph is $4$-[[Arc Transitive Graph|arc transitive]] and also [[Distance Transitive Graph|distance transitive]]. 

* Let $V\subseteq\mathbb{F}^4$ be a vector space over field $\mathbb{F}$ with order $q$.  The **projective space** $\text{PG}(3,q)$ is a system of 1,2, and 3 dimensional subspaces of $V$ referred to as points lines and planes. 
	* Each $1$-dimensional subspace contains $q-1$ nonzero vectors.
	* There are $(q+1)(q^2+1)$ totally [[Quadratic Form|isotropic points]].
	* There are $(q^2+1)(q+1)$ totally isotropic lines.
	* Each totally isotropic point is contained in $q+1$ totally isotropic lines

# Fano Plane
* The **Fano Plane** is a projective plane $\text{PG}(2,2)$  
* It is a $2-(7,3,1)$ design. 
* It is a [[t-Design|Steiner triple system]]

* The incidence graph of the Fano plane is the **Heawood graph**
